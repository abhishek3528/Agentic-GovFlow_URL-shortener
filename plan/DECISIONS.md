| D-017 | 2026-09-08 | Add fallback as a fourth recovery control, ordered retry → fallback → compensate → safe-stop, and route its output through the same completion path as primary work | The assessment names four controls — "bounded retries, fallback, rollback, and safe-stop" — and only three existed, while the README already claimed the fourth in a heading. | D-018 | 2026-09-08 | Give the product its own clock rather than importing `orchestrator.clock` | `app/` depended on the control plane that governs it, inverting the stated architecture. A few duplicated lines buy a one-way dependency, now enforced by an AST check over both package trees rather than by convention | Accepted |
| D-019 | 2026-09-08 | Make human approval reachable by an actual person through `--interactive-approvals`, keeping the scripted provider as the default | The checkpoint was enforced but never exercised: every `Approval` was constructed inside the scenario that needed it, so a run never stopped for anyone. Interactive approval is opt-in because byte-reproducible evidence depends on deterministic fixtures. The provider refuses to run without a terminal rather than reading piped input, since `echo y \| govflow run --interactive-approvals` would otherwise manufacture an approval with nobody present | Accepted |
| D-020 | 2026-09-08 | Derive plans from requirement text, but keep the three scenarios' curated task graphs and say why | Requirements 1 and 2 ask the system to decompose, and it now does — 3 to 11 tasks depending on detected risk, validated by the same `DependencyGraph` as a hand-written plan. The scenarios keep curated graphs because theirs exist to exercise specific controls (a fork meeting a join, a red reproduction gating planning, a re-plan invalidating 5 of 19 artifacts) that a generic plan does not produce. Reproducing them would have required a recogniser per scenario; an earlier iteration did exactly that for S-01 and was removed. Decomposition is therefore demonstrated as a capability and deliberately not the execution path | Accepted |
